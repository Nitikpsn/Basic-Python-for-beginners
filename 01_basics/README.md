# 01 · Basics

Start here. Learn to print output, store values, and work with Python's core data types.

## Files

| File | What you learn |
| --- | --- |
| `hello_world.py` | Your first program -- printing to the screen |
| `variables.py` | What variables are and how to name them |
| `data_types.py` | `int`, `float`, `str`, `bool`, `list`, `tuple`, `dict` |

## Run it

```bash
python3 01_basics/hello_world.py
python3 01_basics/variables.py
python3 01_basics/data_types.py
```

Change the values and run again -- experimenting is how you learn.
