# Basic-Python-for-Beginners

A simple, beginner-friendly Python repository. Made for absolute beginners who want clear examples, practice files, and confidence.

## Who this repo is for

- Students starting Python from zero
- Beginners who feel Python is confusing
- Anyone who wants clean, easy examples

## How to use this repo

1. Open one folder at a time (start at `01_basics`)
2. Read the comments in the code
3. Run the file and experiment
4. Change values and see what happens

## Running the code

Run any example directly:

```bash
python3 01_basics/hello_world.py
```

Run the automated tests (checks every example works):

```bash
python3 -m pip install -r requirements.txt
python3 -m pytest
```

## What is Python?

Python is a high-level programming language used to tell computers what to do in a clear and simple way. It reads almost like normal English, which makes it easy to learn and easy to remember.

People use Python to build websites, create games, analyze data, work with artificial intelligence, automate tasks, and much more.

> If you can explain something in plain words, you can probably write it in Python.

## A short history

Python was created by Guido van Rossum in the late 1980s. He wanted a language that was simple, clean, and enjoyable to use. Python was officially released in 1991.

The name "Python" did not come from the snake. It came from a comedy show called *Monty Python's Flying Circus*, which Guido liked a lot.

From the beginning, Python focused on readability. The goal was to make code look beautiful and logical, not confusing.

## Why Python became so popular

- Easy syntax, perfect for beginners
- Powerful libraries for advanced work
- Works on all major operating systems
- Used by companies like Google, Netflix, and NASA

## Python today

Python is used in:

- Web development
- Artificial intelligence and machine learning
- Data science
- Cybersecurity
- Automation and scripting

Python proves that simplicity can be powerful.
